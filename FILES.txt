Файлы проекта
=============

База данных
-----------
PostgreSQL — основная база данных приложения. Сервер получает строку
подключения из переменной окружения DATABASE_URL. server.js автоматически
создаёт и обновляет таблицы аккаунтов, сессий, приватных диалогов и сообщений.
chat.db — прежняя SQLite-база; она не используется сервером и сохраняется как
источник для одноразового переноса командой npm run migrate:sqlite.
DATABASE.md — настройка PostgreSQL и инструкция по переносу данных.

Код и настройки
---------------
server.js — сервер приложения: API, регистрация и вход, работа с PostgreSQL,
проверка доступа к диалогам и обновления сообщений через Socket.IO.
database.js — пул подключений PostgreSQL и инициализация схемы.
scripts/migrate-sqlite-to-postgres.js — безопасный однократный перенос данных
из chat.db в пустую базу PostgreSQL.
package.json — описание проекта, команды запуска и список зависимостей.
package-lock.json — точные версии установленных npm-зависимостей.
node_modules/ — установленные библиотеки; создаётся командой npm install.

Интерфейс (папка public/)
-------------------------
public/index.html — структура страницы, формы входа, список диалогов,
поиск собеседников, настройки и область переписки.
public/style.css — оформление и адаптивная раскладка для компьютера и телефона.
public/api.js — запросы браузера к серверному API и обработка ошибок.
public/state.js — состояние интерфейса: пользователь, диалоги и текущий экран.
public/components.js — отрисовка списков и сообщений, времени, палитры и
предпросмотра цвета.
public/chat.js — логика интерфейса: вход, поиск, диалоги, отправка сообщений,
настройки профиля и подключение к Socket.IO.
